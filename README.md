# Air7 🏀👟

**E-commerce de zapatillas deportivas (y próximamente bolsos y accesorios)**

Air7 es una página web enfocada en la venta de zapatillas deportivas de las mejores marcas.  
En futuras versiones se sumarán categorías como bolsos, mochilas y accesorios relacionados con el deporte y el streetwear.

Este repositorio contiene la base inicial del proyecto, desarrollado con tecnologías modernas como **React 19**, **Vite**, **Chakra UI**, **TypeScript** y **Biome**.

---

## 🚀 Tecnologías principales

### **Frontend**

- **React 19**
- **TypeScript 5.9**
- **Chakra UI 2.8**
- **Framer Motion 10** (para animaciones)
- **Vite 7** (desarrollo rápido y build optimizada)

### **Herramientas y calidad de código**

- **Biome 2.3.8**  
  Usado para:

  - Linter
  - Formateo
  - Organizar imports
  - Chequeos estáticos avanzados

- **TypeScript strict mode** habilitado:
  - `strict: true`
  - `noUnusedLocals: true`
  - `noUnusedParameters: true`
  - `noFallthroughCasesInSwitch: true`
  - `noUncheckedSideEffectImports: true`
